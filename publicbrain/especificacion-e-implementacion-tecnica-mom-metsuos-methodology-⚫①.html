Documento de Especificación e Implementación Técnica: MOM (MetsuOS Methodology)

1. Introducción y Visión General

MOM (MetsuOS Methodology) es un marco metodológico y de ingeniería de software enfocado en el Desarrollo A Prueba de IA. Se fundamenta en la norma ESA PSS-05 (European Space Agency Software Engineering Standards), aplicando un principio de atomización extrema de especificaciones:

  • Ningún componente, línea de código o documento de usuario se escribe sin trazabilidad previa e inmutable.
  • La verdad del sistema no reside en archivos de texto monolíticos, sino en unidades mínimas independientes (ficheros JSON atómicos).
  • Los agentes de IA (LLMs) no deciden la arquitectura global; únicamente ejecutan, refactorizan u onboardean bajo los límites estrictos (guardrails) impuestos por los esquemas JSON y la jerarquía ESA.
  • Modelo Multiproyecto Standalone: MOM opera como un gestor centralizado que administra un directorio de datos global (data/), permitiendo crear, listar y gestionar múltiples proyectos de forma independiente.
  • Despliegue e Integración de Documentación Target: Además de mantener las carpetas locales de doc/ y vault/ del propio MOM, el motor es capaz de desplegar/copiar automáticamente los entregables generados hacia la carpeta de documentación (docs/) del proyecto destino.
  • Dual-Core Agnóstico y Multiplataforma (Python 3.11+ / C89/C99 y C++98): MOM incluye dos motores paralelos independientes que comparten la misma estructura de datos JSON:
  • Motor Python (mom-py): Basado en Python 3.11+ (stdlib sin dependencias de PyPI), gestionado mediante Poetry.
  • Motor C/C++ (mom-core-native): Implementación nativa escrita en ANSI C (C89/C99) y C++98, sin dependencias externas, compilable de forma nativa en sistemas modernos y sistemas antiguos/heredados (legacy) donde Python 3.11 no esté disponible.

2. Metodología ESA PSS-05 Completa, Flujo de Cambios y Documentación

2.1 Fases del Ciclo de Vida ESA PSS-05

MOM cubre el 100% de la jerarquía de especificación del estándar ESA PSS-05, integrando la documentación de usuario y el onboarding en la misma cascada:

  1. URD (User Requirements Document): Definición de las necesidades del usuario, objetivos del sistema, guía de usuario requerida y onboarding.
  2. SRD (Software Requirements Document): Requisitos funcionales, no funcionales y especificaciones de interfaces/documentación derivables de los URD.
  3. ADD (Architectural Design Document): Diseño de la arquitectura, componentes principales, estructuras de datos, conectores de agentes y módulos de documentación.
  4. DDD (Detailed Design Document): Especificación de funciones, clases, manuales de usuario, contratos de código y archivos de contexto (AGENTS.md).

2.2 Reglas de Trazabilidad e Integridad Estricta

  • Relación de Parentesco Obligatoria:
  • Todo ítem SRD debe incluir al menos un parent_ids hacia un URD.
  • Todo ítem ADD debe apuntar a un SRD.
  • Todo ítem DDD debe apuntar a un ADD.
  • Validación de Huérfanos: No se permite la existencia de elementos en SRD, ADD o DDD que carezcan de padres válidos o apunten a IDs inexistentes.
  • Control de Huérfanos Inversos (Child Integrity): Los enlaces en child_ids deben corresponder simétricamente con los parent_ids del hijo.

2.3 Flujo de Control de Cambios (Change Control & Impact Analysis)

El flujo de modificación de especificaciones, código o documentación sigue el protocolo formal ESA PSS-05:

  1. Propuesta de Cambio (Change Request): Si se propone modificar un componente o guía en DDD (o refactorizar código), el motor de MOM analiza el árbol ascendente (parent_ids).
  2. Análisis de Impacto Ascendente/Descendente:
  3. Ascendente: Comprueba si la modificación viola el contrato definido en ADD, SRD o URD.
  4. Descendente: Identifica todos los nodos hijos (child_ids) afectados en cascada por el cambio de un padre.
  5. Validación de Límites (AI Guardrails): Se verifica que el cambio respete los metadatos de seguridad y restricciones operativas (ai_guardrails) declarados en cada nodo.
  6. Propagación o Bloqueo: Si el cambio altera el contrato superior sin autorización explícita, la modificación se bloquea automáticamente por el compilador.

3. Arquitectura Multiproyecto y Estructura del Repositorio

MOM se organiza de forma que el mismo repositorio aloje tanto el motor Python como el motor C/C++, compartiendo la misma carpeta raíz de proyectos/datos (data/projects/).

4. Motor Nativo C/C++ Agnosticismo y Compatibilidad Legacy

Para garantizar la viabilidad a muy largo plazo y la ejecución en sistemas donde Python 3.11+ no esté disponible, se proporciona mom-core-native.

4.1 Estándares y Dialectos Seleccionados

  • ANSI C (C89/C99): Garantiza compilación sin errores en compiladores clásicos (gcc, clang, MSVC, tcc, watcom) en sistemas Unix antiguos, Windows legacy o arquitecturas embebidas.
  • C++98: Estándar C++ de máxima compatibilidad, evitando características modernas (C++11/14/17/20) para garantizar portabilidad absoluta.
  • Parser JSON Embedded Nativo: Utiliza un parser ligero monolítico en C (por ejemplo cJSON o un tokenizador nativo en un único archivo .c/.h), evitando dependencias de librerías del sistema operativo.

4.2 Instrucciones de Compilación Nativa (COMPILING_NATIVE.txt)

========================================================================
MOM (MetsuOS Methodology) - GUÍA DE COMPILACIÓN DEL MOTOR NATIVO C/C++
========================================================================

Este motor nativo está escrito en C89/C99 y C++98 para garantizar la 
máxima compatibilidad con sistemas modernos y máquinas antiguas/legacy

1. COMPILACIÓN EN SISTEMAS UNIX / LINUX / MACOS (GCC / CLANG)
-------------------------------------------------------------
Para compilar con GCC utilizando el estándar C99:
    gcc -O2 -std=c99 -I native/include native/src/*.c -o mom-native

Para compilar con C++98:
    g++ -O2 -std=c++98 -I native/include native/src/*.cpp -o mom-native

Si se dispone de Make:
    make -f native/Makefile

2. COMPILACIÓN EN WINDOWS (MSVC / MINDEV / CLANG-CL)
-------------------------------------------------------------
Usando el Símbolo del sistema de herramientas nativas de Visual Studio:
    cl /O2 /I native\include native\src\*.c /Femom-native.exe

Usando GCC / MinGW:
    gcc -O2 -std=c99 -I native/include native/src/*.c -o mom-native.exe

3. COMPILACIÓN EN COMPILADORES LEGACY / EMBEBIDOS (ej. TCC, WATCOM)
-------------------------------------------------------------------
Usando Tiny C Compiler (TCC):
    tcc -I native/include native/src/*.c -o mom-native

5.2 Modelos de Datos Nativos (mom/schemas.py)

from enum import Enum
from dataclasses import dataclass, field, asdict
from typing import List, Dict, Any, Optional

class ESAPhase(str, Enum):
    URD = "urd"
    SRD = "srd"
    ADD = "add"
    DDD = "ddd"

class PriorityEnum(str, Enum):
    LOW = "LOW"
    MEDIUM = "MEDIUM"
    HIGH = "HIGH"
    CRITICAL = "CRITICAL"

class StatusEnum(str, Enum):
    DRAFT = "DRAFT"
    REVIEW = "REVIEW"
    APPROVED = "APPROVED"
    REJECTED = "REJECTED"
    DEPRECATED = "DEPRECATED"

class VerificationMethod(str, Enum):
    INSPECTION = "INSPECTION"
    ANALYSIS = "ANALYSIS"
    DEMONSTRATION = "DEMONSTRATION"
    UNIT_TEST = "UNIT_TEST"
    INTEGRATION_TEST = "INTEGRATION_TEST"
    SYSTEM_TEST = "SYSTEM_TEST"

@dataclass
class ItemAttributes:
    priority: PriorityEnum = PriorityEnum.MEDIUM
    verification_method: VerificationMethod = VerificationMethod.UNIT_TEST
    status: StatusEnum = StatusEnum.DRAFT
    is_user_doc: bool = False
    extra: Dict[str, Any] = field(default_factory=dict)

@dataclass
class ItemMetadata:
    author: str = "Metsuke"
    ai_guardrails: Optional[str] = None
    created_at: Optional[str] = None
    updated_at: Optional[str] = None

@dataclass
class MOMItem:
    id: str
    phase: ESAPhase
    title: str
    description: str
    parent_ids: List[str] = field(default_factory=list)
    child_ids: List[str] = field(default_factory=list)
    attributes: ItemAttributes = field(default_factory=ItemAttributes)
    metadata: ItemMetadata = field(default_factory=ItemMetadata)

    def __post_init__(self) -> None:
        if isinstance(self.phase, str):
            self.phase = ESAPhase(self.phase)

        prefix = self.phase.value.upper()
        if not self.id.startswith(f"{prefix}-"):
            raise ValueError(f"El ID '{self.id}' debe comenzar con el prefijo '{prefix}-'")

        if self.phase != ESAPhase.URD and not self.parent_ids:
            raise ValueError(f"Todo ítem de fase {self.phase.value.upper()} debe tener al menos un parent_id")

    def to_dict(self) -> Dict[str, Any]:
        return asdict(self)

    @classmethod
    def from_dict(cls, data: Dict[str, Any]) -> "MOMItem":
        attr_data = data.get("attributes", {})
        meta_data = data.get("metadata", {})

        attr = ItemAttributes(
            priority=PriorityEnum(attr_data.get("priority", "MEDIUM")),
            verification_method=VerificationMethod(attr_data.get("verification_method", "UNIT_TEST")),
            status=StatusEnum(attr_data.get("status", "DRAFT")),
            is_user_doc=attr_data.get("is_user_doc", False),
            extra=attr_data.get("extra", {})
        )
        meta = ItemMetadata(
            author=meta_data.get("author", "Metsuke"),
            ai_guardrails=meta_data.get("ai_guardrails"),
            created_at=meta_data.get("created_at"),
            updated_at=meta_data.get("updated_at")
        )
        return cls(
            id=data["id"],
            phase=ESAPhase(data["phase"]),
            title=data["title"],
            description=data["description"],
            parent_ids=data.get("parent_ids", []),
            child_ids=data.get("child_ids", []),
            attributes=attr,
            metadata=meta
        )

6. Gestor Multiproyecto y CRUD (mom/projects.py y mom/crud.py)

Gestión centralizada del directorio de proyectos data/projects/.

import json
import shutil
from pathlib import Path
from typing import List, Optional
from mom.schemas import MOMItem, ESAPhase

class ProjectManager:
    def __init__(self, data_dir: Path = Path("data/projects")) -> None:
        self.data_dir = data_dir
        self.data_dir.mkdir(parents=True, exist_ok=True)

    def create_project(self, project_name: str) -> Path:
        proj_dir = self.data_dir / project_name
        if proj_dir.exists():
            raise FileExistsError(f"El proyecto '{project_name}' ya existe en {proj_dir}")

        # Crear estructura atómica del proyecto
        for phase in ESAPhase:
            (proj_dir / "src" / phase.value).mkdir(parents=True, exist_ok=True)

        (proj_dir / "doc").mkdir(parents=True, exist_ok=True)
        (proj_dir / "vault").mkdir(parents=True, exist_ok=True)

        # Metafichero de proyecto
        meta = {"name": project_name, "version": "0.1.0", "status": "ACTIVE"}
        with open(proj_dir / "project.json", "w", encoding="utf-8") as f:
            json.dump(meta, f, indent=2)

        return proj_dir

    def list_projects(self) -> List[str]:
        return [d.name for d in self.data_dir.iterdir() if d.is_dir() and (d / "project.json").exists()]

    def delete_project(self, project_name: str) -> bool:
        proj_dir = self.data_dir / project_name
        if proj_dir.exists():
            shutil.rmtree(proj_dir)
            return True
        return False

class MOMRepository:
    def __init__(self, project_dir: Path) -> None:
        self.project_dir = project_dir
        self.src_dir = project_dir / "src"
        self._ensure_directories()

    def _ensure_directories(self) -> None:
        for phase in ESAPhase:
            (self.src_dir / phase.value).mkdir(parents=True, exist_ok=True)

    def _get_file_path(self, phase: ESAPhase, item_id: str) -> Path:
        return self.src_dir / phase.value / f"{item_id}.json"

    def create_item(self, item: MOMItem) -> MOMItem:
        file_path = self._get_file_path(item.phase, item.id)
        if file_path.exists():
            raise FileExistsError(f"El ítem {item.id} ya existe")

        with open(file_path, "w", encoding="utf-8") as f:
            json.dump(item.to_dict(), f, indent=2, ensure_ascii=False)

        self._sync_parent_references(item, add=True)
        return item

    def read_item(self, item_id: str) -> Optional[MOMItem]:
        for phase in ESAPhase:
            file_path = self._get_file_path(phase, item_id)
            if file_path.exists():
                with open(file_path, "r", encoding="utf-8") as f:
                    data = json.load(f)
                return MOMItem.from_dict(data)
        return None

    def list_all(self, phase: Optional[ESAPhase] = None) -> List[MOMItem]:
        items: List[MOMItem] = []
        phases_to_scan = [phase] if phase else list(ESAPhase)
        for p in phases_to_scan:
            p_dir = self.src_dir / p.value
            for f_path in p_dir.glob("*.json"):
                with open(f_path, "r", encoding="utf-8") as f:
                    data = json.load(f)
                    items.append(MOMItem.from_dict(data))
        return items

    def _sync_parent_references(self, item: MOMItem, add: bool = True) -> None:
        for parent_id in item.parent_ids:
            parent = self.read_item(parent_id)
            if parent:
                if add and item.id not in parent.child_ids:
                    parent.child_ids.append(item.id)
                    self._save_raw(parent)
                elif not add and item.id in parent.child_ids:
                    parent.child_ids.remove(item.id)
                    self._save_raw(parent)

    def _save_raw(self, item: MOMItem) -> None:
        file_path = self._get_file_path(item.phase, item.id)
        with open(file_path, "w", encoding="utf-8") as f:
            json.dump(item.to_dict(), f, indent=2, ensure_ascii=False)

7. Compilador y Despliegue en Carpeta Target (mom/compiler.py)

Compila el proyecto y copia automáticamente los entregables a la carpeta docs/ del software externo si se especifica un --target-docs.

import shutil
from pathlib import Path
from typing import Dict, List, Optional
from mom.crud import MOMRepository
from mom.schemas import ESAPhase, MOMItem

class MOMCompiler:
    def __init__(self, repo: MOMRepository, target_docs_dir: Optional[Path] = None) -> None:
        self.repo = repo
        self.project_dir = repo.project_dir
        self.doc_out = self.project_dir / "doc"
        self.vault_out = self.project_dir / "vault"
        self.agents_out = self.project_dir / "AGENTS.md"
        self.target_docs_dir = target_docs_dir

    def validate_graph(self) -> List[str]:
        errors: List[str] = []
        all_items: Dict[str, MOMItem] = {item.id: item for item in self.repo.list_all()}

        for item_id, item in all_items.items():
            for pid in item.parent_ids:
                if pid not in all_items:
                    errors.append(f"[{item.id}] Apunta a un parent_id inexistente: '{pid}'")

            for cid in item.child_ids:
                if cid not in all_items:
                    errors.append(f"[{item.id}] Apunta a un child_id inexistente: '{cid}'")

            if item.phase != ESAPhase.URD and not item.parent_ids:
                errors.append(f"[{item.id}] El elemento de fase '{item.phase.value}' no tiene padres.")

        return errors

    def compile_all(self) -> None:
        self.doc_out.mkdir(parents=True, exist_ok=True)
        self.vault_out.mkdir(parents=True, exist_ok=True)

        # 1. Compilación de documentos consolidados
        for phase in ESAPhase:
            items = self.repo.list_all(phase=phase)
            items.sort(key=lambda x: x.id)

            blocks: List[str] = []
            for item in items:
                guardrail = f"\n> ⚠️ **AI Guardrails:** {item.metadata.ai_guardrails}\n" if item.metadata.ai_guardrails else ""
                parents = f"**Padres:** {', '.join(item.parent_ids)}\n" if item.parent_ids else ""
                children = f"**Hijos:** {', '.join(item.child_ids)}\n" if item.child_ids else ""

                block = f"## {item.id}: {item.title}\n" \
                        f"**Estado:** `{item.attributes.status.value}` | **Prioridad:** `{item.attributes.priority.value}`\n\n" \
                        f"### Descripción\n{item.description}\n\n" \
                        f"{parents}{children}{guardrail}\n---"
                blocks.append(block)

            content = f"# Documentación Consolidada ESA PSS-05 - Fase {phase.value.upper()}\n\n" + "\n\n".join(blocks)
            with open(self.doc_out / f"{phase.value.upper()}.md", "w", encoding="utf-8") as f:
                f.write(content)

        # 2. Compilación de AGENTS.md
        guardrail_items = [i for i in self.repo.list_all() if i.metadata.ai_guardrails]
        blocks = [f"### Componente `{i.id}` ({i.title})\n> 🛑 **Guardrail Inmutable:** {i.metadata.ai_guardrails}\n" for i in guardrail_items]
        agents_content = "# AGENTS.md - Contexto de Onboarding e Instrucciones para IA\n\n" + "\n".join(blocks)
        with open(self.agents_out, "w", encoding="utf-8") as f:
            f.write(agents_content)

        # 3. Copia/Despliegue a carpeta de documentación de destino (si se configuró)
        if self.target_docs_dir:
            self.target_docs_dir.mkdir(parents=True, exist_ok=True)
            for md_file in self.doc_out.glob("*.md"):
                shutil.copy(md_file, self.target_docs_dir / md_file.name)
            if self.agents_out.exists():
                shutil.copy(self.agents_out, self.target_docs_dir / "AGENTS.md")

8. Interfaz CLI Unificada (mom/cli.py)

Menú interactivo y comandos por línea de comandos para gestión de proyectos y compilación.

import sys
import argparse
from pathlib import Path
from mom.projects import ProjectManager
from mom.crud import MOMRepository
from mom.compiler import MOMCompiler

def main() -> None:
    parser = argparse.ArgumentParser(description="MOM (MetsuOS Methodology) Multi-Project Standalone CLI")
    subparsers = parser.add_subparsers(dest="command")

    # Comando: projects
    proj_parser = subparsers.add_parser("projects", help="Gestión de proyectos MOM")
    proj_parser.add_argument("--action", choices=["list", "create", "delete"], required=True)
    proj_parser.add_argument("--name", help="Nombre del proyecto")

    # Comando: compile
    compile_parser = subparsers.add_parser("compile", help="Compila las especificaciones de un proyecto")
    compile_parser.add_argument("--project", required=True, help="Nombre o ruta del proyecto")
    compile_parser.add_argument("--target-docs", help="Ruta destino opcional (ej. /mi-repo/docs)")

    args = parser.parse_args()
    pm = ProjectManager()

    if args.command == "projects":
        if args.action == "list":
            projects = pm.list_projects()
            print(f"📋 Proyectos MOM ({len(projects)}):")
            for p in projects:
                print(f"  - {p}")
        elif args.action == "create":
            if not args.name:
                print("❌ Debe especificar --name para crear un proyecto.")
                sys.exit(1)
            proj_dir = pm.create_project(args.name)
            print(f"✅ Proyecto '{args.name}' creado con éxito en: {proj_dir}")
        elif args.action == "delete":
            if not args.name:
                print("❌ Debe especificar --name para eliminar un proyecto.")
                sys.exit(1)
            if pm.delete_project(args.name):
                print(f"🗑️ Proyecto '{args.name}' eliminado.")
            else:
                print(f"❌ El proyecto '{args.name}' no existe.")

    elif args.command == "compile":
        proj_dir = Path("data/projects") / args.project if not Path(args.project).is_absolute() else Path(args.project)
        if not proj_dir.exists():
            print(f"❌ La ruta del proyecto no existe: {proj_dir}")
            sys.exit(1)

        repo = MOMRepository(proj_dir)
        target_path = Path(args.target_docs) if args.target_docs else None
        compiler = MOMCompiler(repo, target_docs_dir=target_path)

        errors = compiler.validate_graph()
        if errors:
            print("❌ Error de validación en el grafo del proyecto:")
            for err in errors:
                print(f"  - {err}")
            sys.exit(1)

        compiler.compile_all()
        print(f"✅ Proyecto '{proj_dir.name}' compilado correctamente.")
        if target_path:
            print(f"📦 Documentación desplegada automáticamente en: {target_path}")

    else:
        parser.print_help()

if __name__ == "__main__":
    main()
